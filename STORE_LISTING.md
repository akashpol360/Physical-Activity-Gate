# Store listing draft

## Name
Physical Activity Gate

## Short description
Complete a physical activity before opening the apps that distract you.

## Full description
Physical Activity Gate adds a deliberate physical step before selected social-media and entertainment apps.

Choose the apps you want to protect, assign an exercise such as squats, push-ups, jumping jacks, plank, sit-ups or steps, and set how long the app stays unlocked after completion.

### Privacy-first
- Local-first operation
- No account required
- No cloud dependency
- Camera exercise processing stays on the device
- No exercise videos are uploaded
- Optional usage statistics remain local

### Control
- Per-app activity rules
- Temporary unlock duration
- Require activity every time
- Daily unlock limits
- Cooldown
- Emergency bypass controls
- Optional settings PIN

Accessibility Service is used only for the user-enabled protected-app access-control feature and must be explicitly enabled in Android Settings.
