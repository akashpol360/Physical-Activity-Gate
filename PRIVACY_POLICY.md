# Physical Activity Gate — Privacy Policy

Physical Activity Gate is designed to operate locally on the Android device.

## Data processed
The app stores local configuration, protected-app rules, activity sessions, statistics, achievements, authorization state and optional usage statistics. Camera frames used for exercise verification are processed on-device during an active exercise session and are not uploaded or intentionally stored as recordings.

## Network
The core application does not require an account, cloud service, Firebase, REST API, or internet connection.

## Permissions
- Camera: only for camera-based exercise verification.
- Activity Recognition: for supported step verification.
- Notifications: for optional local reminders/expiry notifications.
- Usage Access: only when the user enables usage statistics.
- Accessibility Service: used only for foreground protected-app access control after the user explicitly enables it in Android Settings. Reads only the package name of the app owning each open window (including floating/split-screen windows) — never on-screen text, images, or other content.

## User control
Permissions can be denied. Some features will not operate when their required permission is unavailable. The app does not claim that Android restrictions can make itself impossible to uninstall or disable.
